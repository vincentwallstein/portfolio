# Vincent Wallstein Engineering Portfolio

Static HTML portfolio deployed through Netlify from GitHub.

- `index.html`: homepage, with portrait in `images/vincent-wallstein.jpg`
- `projects.html`: project portfolio
- `resume.html`: embedded résumé PDF viewer
- `resume-vincent-wallstein.pdf`: downloadable résumé
- `images/`: image assets

Netlify publish directory: repository root (`.`). No build command is needed.
